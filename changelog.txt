Below is a summart of changes made to the card in descending order:


20260408

- _warn(msg, ...args) — a small helper that prefixes all console warnings with [ParcelApp Card <version>] so they're easy to filter in the browser console.
- setConfig → _applyConfig split — the config body moved into _applyConfig. setConfig now wraps it in try/catch and logs the received config object + full error before re-throwing. This means the next "Configuration Error" will show exactly what config HA passed in and what went wrong.
- set hass → _renderHass split — same pattern. Runtime rendering errors (bad deliveries shape, unexpected null, etc.) are caught, and the card logs the active config + entity state at the time of failure instead of silently exploding.
- deliveries shape check — if the entity exists but has no deliveries array attribute, a warning is logged with the full attributes object so you can see what the entity actually looks like.
- To see the logs: open browser DevTools → Console, and filter by ParcelApp.
